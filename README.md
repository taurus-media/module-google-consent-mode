# Google Consent Mode module #

This module is designed to communicate consent mode to GTM. 
When customer selects which cookies he accepts on frontend, this information gets pushed to dataLayer.

### Requirements ###
This module will work only with a combination of Amasty Cookie Consent (GDPR) and Magepal GoogleTagManager modules.

### Usage
You can link cookie groups with specific consents under:

_Stores > Configuration > Taurus > Google Consent Mode > Consent Mode Mapping_
